AsianScore Developer Documentation

AsianScore Public Sports Data & xG Ledger REST API

Free, keyless, HTTPS & CORS-enabled JSON endpoints for real-time Football & NBA scores, Dixon-Coles expected goals (xG), and pre-kickoff SHA-256 verifiable prediction ledger snapshots.

Base URL: https://asianscore.com Auth: None (Keyless) HTTPS: TLS 1.3 CORS: Access-Control-Allow-Origin: *

Endpoints

Method & PathDescriptionLive Test
GET /api/widget/summaryCompact scoreboard & aggregate ledger calibration stats (locked count, hit rate, avg Brier score)JSON
GET /api/ledgerFull SHA-256 verifiable prediction ledger (accuracy, byLeague, recentSettled, upcomingLocked)JSON
GET /api/scoresLive & upcoming matches across 30+ football leagues & NBA with market odds & predicted scorelinesJSON
GET /api/articlesPre-match previews and tactical post-match analysis articlesJSON
GET /embed.jsZero-dependency embeddable scoreboard widget scriptJS

Quickstart (cURL & Python)

curl -s https://asianscore.com/api/widget/summary | jq '.ledger'
pip install asianscore-quant
python -c "import urllib.request, json; print(json.loads(urllib.request.urlopen('https://asianscore.com/api/ledger').read())['accuracy'])"
